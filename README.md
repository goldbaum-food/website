# Goldbaum Website

Statische Website in drei Sprachen:

- `en/index.html` Englisch
- `de/index.html` Deutsch
- `es/index.html` Spanisch
- `index.html` leitet Besucher auf Englisch weiter
- `og-image.jpg` Vorschaubild für geteilte Links (LinkedIn, WhatsApp usw.)

Die Sprachlinks verwenden relative Pfade (`../de/` usw.). Lokal im Browser zeigen sie auf den Ordner, auf dem echten Server öffnet sich automatisch die Seite.

## Veröffentlichen

Den **Inhalt** dieses Ordners (nicht die ZIP selbst) in das Hauptverzeichnis eines GitHub-Repositorys hochladen und GitHub Pages aktivieren (Branch `main`, Ordner `/`). Danach `goldbaum.food` als eigene Domain eintragen und die DNS-Einträge beim Domain-Anbieter setzen.

## Vor dem Livegang

Impressum und Datenschutzerklärung vervollständigen (derzeit Platzhalter).
